# 🛡️ RamsomSense

An end-to-end machine learning project that analyzes ransomware attack data to predict:

- Attack Severity
- Estimated Financial Loss
- Downtime
- Probability of Ransom Payment

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-Learn
- Streamlit
- SHAP
